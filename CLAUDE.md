# Required instructions for Claude

Before making any design, artwork, scene, gallery, or visual-code change, read `docs/DESIGN_CONTRACT.md` in full.

The sword set, approved figure/miniature reference(s), and the single album are locked assets. You may adjust surrounding room decor, framing, theme, or a Pixiv-inspired rendering treatment only if the locked assets retain their approved concept-art identity, placement, purpose, and recognisable silhouette. Never invent a replacement, simplify them into generic fantasy props, or remove them.

For any image/design operation, use `astra-light` only. If it is not available, stop and tell the owner; do not fall back to another model. If the source art is absent from `public/references/locked/`, do not claim an exact reconstruction; request the source file or work only on unlocked areas.

This instruction takes priority over visual-polish or refactor suggestions.
