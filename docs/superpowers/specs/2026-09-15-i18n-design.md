# i18n: Vietnamese, English, Japanese

Status: approved by owner (2026-09-15)

## Goal

Every visitor-facing string is available in Vietnamese (`vi`), English (`en`) and Japanese (`ja`) without adding a dependency.

## Language selection

- A `VI · EN · JA` button group sits in the top bar next to the sound toggle (a setting, not a navigation shortcut).
- First visit: the first match in `navigator.languages`; otherwise English.
- An explicit choice is stored in `localStorage` (`tho-vn:locale`).
- Switching keeps the current place and dialogue step; only text changes.
- `<html lang>`, `<title>` and the meta description follow the language.

## Architecture

- Structure stays in one place: node ids, choice targets, step status and sources (`story.ts`), project ids, names, companies, dates, stacks and deep-dive links (`projects.ts`), CV dates (`cv.ts`), contact values (`site.ts`).
- Text lives in `src/content/i18n/{en,vi,ja}.ts`, each typed as `LocaleContent`. Story steps are fixed-length tuples per node, so a missing or extra step fails `tsc`.
- `src/content/index.ts` builds one `Content` object per language at module load (story, localized projects, `getProject`).
- `src/i18n/LocaleProvider.tsx` exposes `useLocale()` → `{ locale, setLocale, content }`.
- Step counts are identical across languages; navigation uses the English story for them.
- Speakers are ids (`tho`, `note`); display names come from the locale.

## Translation status

Each locale has `translationStatus: 'draft' | 'ready'`. Vietnamese and Japanese start as `draft`: in review mode (`site.review.showContentStatus`) every step and the project/CV panels show a "draft translation · needs Thọ to confirm" tag. Set it to `ready` after review.

Not translated: proper nouns, technology names, numbers, dates, the CV PDF, gallery item titles (the list is empty), and the unmounted `Collection.tsx`.

## Typography

Japanese fallback fonts are added to both font stacks. `:lang(ja)` uses `line-break: strict` and `word-break: auto-phrase`.

## Verification

- `npm run build` (type-checks translation completeness).
- Responsive QA script at 11 viewport sizes for each language; inspect Vietnamese and Japanese screenshots directly.
