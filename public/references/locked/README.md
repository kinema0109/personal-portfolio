# Locked source artwork

Put the owner-provided, untouched original reference images here. These files are the canonical inputs for the locked sword set, figures, and desk album described in `docs/DESIGN_CONTRACT.md`.

Do not edit, resize, optimise, recolour, or overwrite files in this folder. Create derived pixel-art assets elsewhere (for example `public/art/derived/`) and record each source filename plus SHA-256 checksum in the design contract.
